# 2.8.0

## SOLID architecture hardening

- Depend on abstractions: the agent now takes `IChiefOfStaffOrchestrator` instead of the concrete orchestrator, with interface mappings in the composition root.
- Single-responsibility split: response-policy formatting moved to an injectable `IResponsePolicyFormatter` service; agent statics delegate to it with no behavior change.
- Open/closed extension points: capability and event dispatch now consult `ICapabilityHandler` / `IAgentEventHandler` registries first, so new capabilities and events can be added without editing the agent.
- Injectable policies: operating-profile registry (`IOperatingProfileRegistry`), game-studio ownership policy (`IGameStudioOwnershipPolicy`), and manager selection (`IManagerSelector<T>`) are registered in DI with behavior-preserving defaults.
- Dead-code removal: deleted the `WriteRunLogAsync` no-op stub and unused orchestrator helpers.
- Guardrails: new `SolidGuardrailTests` lock in DIP/OCP/SRP seams and verify default policies preserve historical behavior.

No manifest capability or configuration changes. No migration steps.
