# 2.16.2

- Fixed release creation failing permanently on temporary GitHub server or transport errors. Publishing now uses bounded retries and preserves useful diagnostics.
- Fixed reruns reporting success for an empty draft left by failed release creation. The workflow resumes missing draft uploads, verifies the bundle and checksum, publishes the draft, and confirms its public state.
- Existing published releases and mismatched assets are never overwritten. Authentication and permanent API errors fail visibly rather than being treated as a missing release.

Includes the 2.16.1 onboarding fix. No new grants, configuration changes, or breaking APIs. Publish through the release workflow and update through Installed Agents.
